What we built this weekend

A shortcut that still learns.

1

Generate a synthetic symbolic dataset — thousands of episodes rolled out offline, no rendering needed.

2

Train a simple policy on it with Bellman updates — cheap, deterministic, runs on a laptop.

3

At inference, the policy drives — but a VLM infers the state from what it sees, turning it into a POMDP.

The model never sees the symbols at run time — only the world, the same way we do.
