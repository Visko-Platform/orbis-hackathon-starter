# Cutline 1.0

A shared film directed by the audience. Reactor carries a continuous Visko Orbis stream; Nebius turns the winning choice and saved story memory into a coherent next scene.

The creator controls live cues, audience voting, alternate story branches, memory, exports, and a ten-second recording. Audience phones synchronize votes with server-sent events. A continuous interactive 3D cosmic flight is being finalized for this release; select destinations on screen before entering the live film.

See VERIFICATION.md for measured checks and limits, STARTER.md for the official Visko adaptation, and PROVENANCE.md for media credits.
