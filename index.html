See the loop

The theater screen shows the video. Audience phones show the room, the choices, the vote totals, and the winning decision.

01 · SCENEA live Orbis scene plays on the shared screen.
02 · CHOOSEAudience phones get three choices. Votes can change until the director closes.
03 · DECIDEThe vote closes; tallies and the winner are frozen atomically.
04 · PLANNebius turns the winning choice into a coherent scene direction with story memory.
05 · STEERThe direction is sent to the running Orbis world through Reactor. The next moment is generated live.

What you can do

LIVE

Start live cinema

A creator-only endpoint mints a scoped Reactor session; the browser receives Orbis video and audio over WebRTC.

DIRECT

Direct a visible change

Send a short instruction or use four live cues. The UI distinguishes sending, provider acceptance, and the next received chunk.

ROOM

Invite the room

Share a link or QR code. Separate browsers vote; a vote can be changed until voting closes.

DECIDE

Make a collective decision

Close voting, freeze the result, apply the winning action exactly once. Ties follow displayed order.

MEMORY

Preserve continuity

Character, clothing, setting, and style live in editable story memory that the Nebius director receives.

BRANCH

Explore another ending

Return to any saved scene and continue along a new branch. Every branch stays in the exported story graph.

COSMOS

Cosmic opening

Fly through a continuous 3D scene built from NASA imagery, from the Webb deep field to Earth to San Francisco to the film.

EXPORT

Keep the result

Export Markdown and JSON story data, and record clips of the actual live media in the browser.

Run it yourself

The full interactive app (voting, live Orbis video, story branching) is a Cloudflare Worker with a D1 database. Run it locally in three commands, or deploy your own copy to Cloudflare.

git clone https://github.com/vnmoorthy/cutline.git && cd cutline
npm run install:ci && npm run build
npm run dev -- --port 3000     # open http://localhost:3000
npx wrangler login && npm run deploy     # your own public HTTPS copy on Cloudflare Workers

Rehearsal mode works with no API keys. Add REACTOR_API_KEY and NEBIUS_API_KEY for live Orbis video and AI scene planning. See the demo runbook for a scripted product demo.
