# Quick Task 260912-m35: Add buttons to go to the live view Summary

Added an "Enter their live world →" button to each of the three grandmother cards on `/explore-grandmas-world`, deep-linking to `/live-world?memoryId=seed-<person>` so viewers can jump straight into that grandmother's curated live scene without going back through the FamilyGallery.

## What Was Built

- Added a `liveMemoryId: string` field to the local `Memory` type in `app/explore-grandmas-world/page.tsx`.
- Populated `liveMemoryId` on all three `MEMORIES` entries with hardcoded literals matching `LiveWorld.tsx`'s `SCENES` keys: `lola` → `"seed-lola"`, `yay` → `"seed-yay"`, `babushka` → `"seed-babushka"`. Existing short `id` values (used as React keys) were left unchanged.
- Added a footer row below the memory paragraph in each card containing one `fw-btn fw-btn-primary` anchor: `href={`/live-world?memoryId=${encodeURIComponent(m.liveMemoryId)}`}`, label "Enter their live world →".
- Added `flex: 1` to the card-body `div` and wrapped the new anchor in a `div` with `marginTop: "auto", paddingTop: 14` so all three buttons bottom-align across the row regardless of memory-text length, mirroring `FamilyGallery.tsx`'s CTA-row pattern.
- Page remains a server component: no `"use client"`, no `next/link`, no router hooks, no event handlers, no hardcoded `vercel.app` origin.
