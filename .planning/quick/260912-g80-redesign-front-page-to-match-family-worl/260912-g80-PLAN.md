# Quick Task 260912-g80: Redesign front page to match "Family World" design import

Import the "Family World" modernist design (Claude Design project
868bef8e-ac73-4d10-8db7-6a61a92c86e8, file `Front Page.dc.html`) via the
Claude Design MCP and implement it as the real Next.js front page at
`my-orbis-app/app/page.tsx`, plus add a Google sign-in control at the top
right of the nav.

## Source design

Read directly from the Claude Design MCP (`DesignSync` read methods —
`get_project`, `list_files`, `get_file`):
- `Front Page.dc.html` — page structure/copy/behavior (nav, hero, family
  gallery grid of 3 seed relatives, drag-and-drop "add someone" tile +
  form, accent CTA band, footer)
- `_ds/modernist-.../styles.css` — design tokens (colors, Archivo font,
  spacing, 0-radius "modernist" look) and component classes (`.btn`,
  `.nav`, `.field`, `.input`, `.tag`)
- `support.js` — DC preview runtime only; not needed for the Next.js port

## Tasks

1. **Scope the design tokens to the front page only.** The app's
   `globals.css` hard-sets `html body` to a dark theme used by `/session`
   and other routes. Port `styles.css` into a new
   `my-orbis-app/app/family-world.css`, rewriting `:root`/bare element
   selectors to be scoped under a `.family-world` wrapper class and
   prefixing component classes `fw-*`, so nothing leaks outside the front
   page. Files: `my-orbis-app/app/family-world.css` (new).

2. **Port the interactive family gallery to a client component.** The
   DC template's inline `Component extends DCLogic` state machine (seed
   relatives, add/remove, drag-and-drop file read, form validation, toast)
   becomes a `"use client"` React component using `useState`/`useRef`.
   Files: `my-orbis-app/app/components/FamilyGallery.tsx` (new).

3. **Add a Google sign-in control for the nav.** Front page stays public
   (middleware only gates `/session` and `/api/reactor/*`); this is a
   convenience so the presenter can sign in from the landing page. Server
   Component using the existing `auth`/`signIn`/`signOut` from
   `my-orbis-app/auth.ts` via inline Server Actions (Auth.js v5 App Router
   pattern) — shows "Sign in with Google" when signed out, email + "Sign
   out" when signed in. Placed as the rightmost nav element (top right).
   Files: `my-orbis-app/app/components/GoogleSignInButton.tsx` (new).

4. **Rewrite the front page** to compose nav (brand, tagline, "Add
   someone" anchor, `GoogleSignInButton`) + hero + `FamilyGallery` + accent
   CTA band + footer, matching the design's copy and layout, using
   `next/font/google` Archivo instead of the design's `@import` font URL.
   Files: `my-orbis-app/app/page.tsx` (rewritten).

5. **Add the two missing seed photos** referenced by the design (Yay /
   Phnom Penh, Babushka / Leningrad) to `public/images/` — copied from
   `.planning/spikes/006-world-select-landing/`, which already holds
   verified spike assets at the same relative filenames the design
   references. Files: `my-orbis-app/public/images/phnom-penh-1964.jpg`,
   `my-orbis-app/public/images/leningrad-1980s.jpg` (new).
